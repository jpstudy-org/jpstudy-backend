# 도메인 계층
- 가장 중요한 비즈니스 규칙은 무엇인가?

## 주요 역할
- 핵심 비즈니스 규칙 및 상태 관리
- 도메인의 일관성 유지

## 주요 구성 요소
- Entity : 고유한 식별자를 가지며, 라이프사이클을 갖는 객체
- VO : 불변하며, 값 자체로 의미를 갖는 객체
- Aggregate : 관련된 Entity, VO 묶음으로 데이터 일관성을 관리하는 단위
- Repository : Aggregate의 영속성을 처리하기 위한 인터페이스 정의
- Domain Service : 특정 Entity나 VO에 속하지 않는 복잡한 도메인 로직 처리
- Domain Event : 도메인에서 발생한 중요한 사건

- 외부 기술에 대한 의존성이 없어야 함. 순수 Java 코드로 작성하며 DB, 프레임워크 등 외부 요소로부터 분리되어야 함
